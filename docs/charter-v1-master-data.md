# V1 章程：主数据（PC）

## 产品

离散制造 MES，面向精密 / 电子 / 机加。私有化部署，多工厂。工厂之间数据隔离；主数据可共享，并允许工厂级扩展。

第一刀只做 PC 端主数据管理。不做 PDA。

## 范围内（后续实现，此处只定范围）

- 工厂、车间、工作中心
- 人员、班组、工厂任职、简单角色
- 物料分类、计量单位、物料、BOM
- 工序、工艺路线（版本 + 返工分支）
- 设备
- 不良代码 / 原因代码
- 自定义字段：文本、数字、日期时间、单选、多选、布尔、图片、文件；支持必填与校验；按工厂配置。表单策略见 [架构备忘](architecture.md) 的「动态表单」。
- 数据字典、编码规则
- Excel 导入 / 导出
- 物料、BOM、工艺路线的版本状态：草稿、发布、作废

## 范围外

PDA，排程与报表，检验执行，完整追溯，工装与仓库，技能，标签，SaaS 多租户，可视化表单设计器。

## 原则

界面和文档保持薄。领域模型留扩展位（工厂扩展、版本、自定义字段），不预写空业务模块。

自定义字段的 V1 界面用 Ant Design Form 加一层自研 Schema 渲染器，不引入 Formily。字段定义保持 JSON Schema 友好（闭合的 `type`、选项、校验、布局提示），以便日后改用 FormRender 时只换渲染器，不改领域元数据。
